Batalla Naval con TCP y UDP

En esta actividad se desarrolló un juego de Batalla Naval en Python utilizando una arquitectura cliente-servidor.

Primero se implementó la comunicación mediante el protocolo TCP, permitiendo que dos equipos se conectaran y enviaran información de manera confiable durante la partida.

Posteriormente se realizó una segunda versión utilizando UDP, con el objetivo de observar las diferencias entre ambos protocolos de transporte.

La práctica permitió comprender de forma básica el funcionamiento de los sockets, la comunicación entre cliente y servidor y el uso de TCP y UDP dentro de una aplicación de red.
